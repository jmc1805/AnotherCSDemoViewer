Overwatch - Trust Analysis statistical indicators vs. rank-banded baselines · evidence for review, not a verdict
What am I looking at?
Each card is one player. Every indicator (hover its name for what it measures) is compared against other players at the same rank - never against everyone, since a Global Elite and a Silver naturally look different on these stats. Nothing here is a verdict: legit players hit outliers too, especially with few matches analyzed.
Suspicion bar / percentile
Where this value ranks against same-rank players (e.g. "97th" = higher/more suspicious than 97% of peers). Highlighted amber ≥95th, red ≥99th. Grey "n/a" means too few baseline samples exist yet to compare against.
+X.Xσ*
Peer z-score - how far above this match's own 10 players the value is, shown only when notably high. A same-match sanity check alongside the baseline comparison.
vs Cheat%
Percentile against a small reference pool of confirmed-cheater matches (only shown once that pool has enough samples). Higher = closer to how confirmed cheaters score.
Z·2.9 / Zs·1.8
Composite score combining every suspicious feature into one number. "Zs·" is the same score after down-weighting indicators backed by very few events this match toward the rank baseline - shown only when it meaningfully differs from "Z·", so you can spot scores resting on a thin sample.
Hover an indicator
Shows what it measures, this match's value, its 95% confidence interval (the plausible range given how few events back it - wide with few events, tight with many), and how many events that's based on.
Pooled evidence
On the Overwatch dashboard, a player flagged in ≥2 matches gets this same value re-estimated from every one of their other analyzed matches - a tight interval over many matches is much stronger evidence than one match's outlier.
