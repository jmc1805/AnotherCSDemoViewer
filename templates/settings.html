About the external tools below

Some cards below point this app at third-party programs (HLAE, ffmpeg, Source2Viewer-CLI) that you download and install yourself. This app just stores the path you give it and runs whatever is there - it can't check what that is. So grab them from the official project pages, and verify checksums or signatures where the project publishes them.

Import Icons Manually

        

            An alternative to the extraction above, for machines that can't do it -
            no CS2 install and no Source2Viewer-CLI needed, because the icons are
            just image files. Extract them once on a machine that has the game, then
            bring them here.
